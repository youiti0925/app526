## 2. 何を作っているか

副業の仕事を、アプリとAIで ①案件探し → ②判定 → ③手順書 → ④作業 → ⑤検品 → ⑥やり直し まで進め、
ユーザーは ⑦承認（と、応募・納品の送信）だけ行う仕組み。

- ユーザー: 会社員。使える時間は週10時間ほど。スマホから話すことが多い。PCは Windows（使うときだけつける）
- 主な場: クラウドワークス。ほかにココナラ公開依頼・ままワークス（公開されている分だけ自動で取得）
- 方針（2026-10-17 に決定）: **評価がゼロのうちは、小さく簡単な仕事で評価を積み、大きい仕事につなげる**。
  時給は「自動化した後に、ユーザーが手を動かす時間」で割る。自動化できる仕事なら、単価が安くても通す

## 3. 全体の作り

### 3-1. コマンド（ふだん使うのはこの3つ）

| コマンド | 何をする | AI |
|---|---|---|
| `node scripts/job.mjs judge --text 募集.txt` | 募集文1件を判定し、提案文まで出す | 使う（sonnet・超高） |
| `node scripts/job.mjs run --title 件名 --instructions 依頼.txt --input 表.xlsx` | 受注した仕事を①〜⑥で処理し、納品物（Excel/CSV）を出す | 使う |
| `node scripts/job.mjs thread --text 画面.txt` | クラウドワークスの「相談から契約まで」の画面を読み、返事待ち・危険信号・提示額のミスを出す | 使わない |
| `node scripts/job.mjs scan [--max 100]` | 公開されている募集（ココナラ・ままワークス）を取りに行って判定 | 使う |
| `node scripts/cw-patrol.mjs setup / run / test-mail` | クラウドワークス巡回（PC専用。5章） | judge 経由で使う |
| そのほか | `approve / reject / redo / resume last`、`lead last applied|won|lost|archived`、`profile --file 経歴.txt`、`status`、`usage` | |

`job.mjs` は起動のたびに `git pull --ff-only` で最新を取り込み（`JOB_AUTO_PULL=0` で止まる）、必要ならコンパイルする。

### 3-3. モデルの使い分け（ユーザーのルール）

設計・修正 = opus・中 ／ 処理 = sonnet・超高（xhigh） ／ 軽い判断 = sonnet・中。haiku は使わない。
`models.ts` の `tierModel` / `tierEffort`。環境変数 `JOB_MODEL_*` / `JOB_EFFORT_*` で差し替え可。
AIはサブスクの Claude Code を `claude -p` で呼ぶ（`--safe-mode`、`--bare` は使わない＝サブスクのログインが読めなくなる）。

## 4. 判定の考え方（大事なところ）

1. **詐欺・関門で落とす**（AIが何と言っても通さない）。危険（danger）は見送り
2. **作れるか**：電話・訪問・撮影など体が要るもの、本人の体験や回答そのものが商品のもの（アンケート・レビュー）は受けない
3. **時給 ＝ 手取り ÷ あなたが手を動かす時間**。手取りはクラウドワークスの手数料22%と振込500円を引いた額。
   基準は 1,121円（学習で変わる）。Claudeに判定を任せた案件も同じ割り方で検算する（`escalation.ts`）
4. **実績づくり**：受けた仕事が5件になるまでは、あなたの時間3時間以内・時給500円以上・危険信号と確認事項なしなら通す
5. 「安全」とは言わない。危険信号が見つからなかっただけ

## 5. クラウドワークス巡回（PC専用）

- PCで本人のログインのまま、3時間ごととログオン5分後に、相談中のやり取りと登録した検索条件の新着を見て回る
- 返事が要るもの・危険信号・提示額のミス・新着の応募候補（提案文の下書きつき）を Gメールにまとめて送る
- 見るだけ。応募・返信・送信・ボタン操作はしない。ページごとに6〜12秒あける。1回にやり取り15件・新着10件まで
- Edge を使う（`playwright-core` 1.56。古い版は今の Edge で起動できない）
- Gメールは「アプリ パスワード」で送る（`%USERPROFILE%\.cw-patrol\config.json`。GitHubには入れない）
- **本物の画面ではまだ一度も動かしていない**（偽のCW画面で最初から最後までは確認済み）。初回は `node scripts/cw-patrol.mjs run --show` で画面を見ながら

## 6. GitHub に置くもの・置かないもの

| 置く | 置かない（PCの中だけ） |
|---|---|
| プログラム、ドキュメント、テスト | 依頼者の資料・納品物（`outbox/`・`data/`。守秘のため） |
| `library/`（手順書・経歴・使用量）※非公開にしてから | CWのログイン状態（`.cw-patrol/browser-profile`） |
| | Gメールのアプリ パスワード、巡回の既読記録 |

`library/` は、リポジトリが公開設定のあいだは保存しない作り（`--push` が公開かどうかを確かめる）。
非公開にすれば自動で保存されるようになる。ただし非公開にすると、1行インストールの URL は使えなくなる
（PCで最新を取るときに、一度だけGitHubのログインが出る）。
