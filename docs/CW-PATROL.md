# クラウドワークス巡回（WindowsのPCで自動）

PCを使っている間、3時間ごと（とログオンの5分後）に、あなたのログインのままクラウドワークスを見て回り、
知らせることがあればGメールにまとめを送ります。

- やること: 相談中のやり取りを読んで「返事が要るもの」「危険信号」「提示額のミス」を出す。
  登録した検索条件の新着を判定し、応募候補には提案文の下書きを付ける
- あわせて、公開募集（ココナラ・ままワークス）の自動収集（scan）も毎回回し、応募候補と提案文を同じメールにまとめる（止めるときは `run --no-scan`）
- 読んだ募集の予算を `.cw-patrol\budget-log.jsonl` に記録し、まとめの末尾に Excel/VBA の予算の中央値などを付ける（`node scripts/cw-patrol.mjs budgets` で見られる。検索画面は `add-search <URL>` で足せる）。固定報酬と時給は分けて数える。`survey [--max 30] [--fresh]` は、登録した検索画面の募集の報酬だけを（判定も応募もせず）集めて、1件ずつ「画面の表示」と読んだ金額を並べる
- 応募の下書き一覧: 判定が「応募してよい／確認してから応募」の募集は、応募画面を開いて待たずに、`%USERPROFILE%\.cw-patrol\queue.md`（と巡回のメール）に並べる。
  依頼者の欄（募集実績・総合評価・プロジェクト完了率・本人確認）を読み、**募集実績が多く評価・完了率が高い依頼者を上に**出す。評価か完了率が低い依頼者は「注意」にして、「応募してよい」を「確認してから応募」に下げる。
  一覧の項目: 応募画面のリンク・報酬（時給は手数料を引いた手取りつき）・応募人数・期限・依頼者・判定・提案文・送る前に見ること
  - 承認: スレッドに「承認 3 5」のように番号を返す → `queue-mark approved 3 5` → `fill --approved` で、承認した件だけ入力済みの応募画面を開く（最大5件）。**「応募する」を押すのは自分**。承認のない件は入力も送信もしない
  - 提案文に【要確認】○○が残っている件は、`fill` が入力しない。人が直した提案文は `queue-add <募集URL> --proposal 提案文.txt` で一覧に足す（同じ募集なら差し替え）
  - 送ったら `queue-mark sent 番号`、送らないなら `queue-mark skipped 番号`
- やらないこと: 応募・返信・メッセージ送信・ボタン操作。ページを開いて文字を読むだけ。ページごとに6〜12秒あける
- パスワード: クラウドワークスのパスワードは、Edgeにあなたが入力するだけ。Gメールは「アプリ パスワード」を
  このPCの `%USERPROFILE%\.cw-patrol\config.json` にだけ保存する。どちらもリポジトリにもClaudeにも渡らない

## 準備（1回だけ）

1. スタートボタンを右クリック →「ターミナル」（または「Windows PowerShell」）を開く
2. 次の1行を貼って Enter:
   ```
   irm https://raw.githubusercontent.com/youiti0925/app526/claude/auto-side-hustle-app-plz2sh/scripts/windows/install.ps1 | iex
   ```
3. あとは画面の案内どおりに:
   - 「このアプリがデバイスに変更を加えることを許可しますか」と出たら「はい」（Node.js と Git を入れるとき）
   - ブラウザが開いたら、Claude にいつものアカウントでログイン
   - Edge が開いたら、クラウドワークスにログイン（Googleでのログインも使えます）→ その Edge の窓を閉じてから、黒い画面で Enter
   - Edge で探したい言葉（例: データ入力）を検索し、新着順にして Enter
   - Googleの「アプリ パスワード」のページが開くので、名前に「CW巡回」と入れて作成 → 16文字を黒い画面に入力
   - 「設定の確認」のメールが届けば完了。自動実行も登録される

## スマホから、このPCで動くClaudeと話す

デスクトップの「Claude（app526）」をダブルクリック（窓は開いたままにする）→ スマホの Claude Code アプリに「app526 PC」が出る。
PCがついている間だけ使える。最初に CLAUDE.md を読むので、これまでの決まりごとは引き継がれる。

## 使う

- Gメールに「【CW巡回】返事が要るN件・新着候補N件」が届く。新しいことが無い回は送らない
- 応募候補の提案文は、内容を確かめてから、あなたがクラウドワークスで送る
- 今すぐ1回回したい: `cw-patrol-run.cmd` をダブルクリック（記録は `%USERPROFILE%\.cw-patrol\patrol.log`）
- 止める: `cw-patrol-unregister.cmd`
- 3時間ごとの自動実行が動かないとき: `node scripts/cw-patrol.mjs schedule` で登録をやり直す（電池で動いているときも動かし、PCが寝ていて飛ばした分は起きたあとに1回回す設定つき）
- `fill` は、提案文に【要確認…】や○○などの書きかけの印が残っていると入力しない（事実を確かめて書き直してから）
- 「ログインが切れました」と届いたら: `cw-patrol-setup.cmd` をもう一度

## 分かっていること・まだ確かめていないこと

- 本物のクラウドワークスの画面とGメールでは、まだ一度も動かしていない（開発環境にあなたのログインが無いため）。
  初回はおかしな所が出る前提で、`patrol.log` の中身か、届いたメールを専用の会話に貼ってください
- 画面の作りが変わると読めなくなる。読めないときは「うまく読めなかったもの」に出る
- クラウドワークスの利用規約に自動アクセスを禁じる明文は見つけていないが、運営はAIによる巡回を断っており、
  「不適当と判断した行為」での利用停止の条項はある。回数と速さを絞っているのはそのため
- 判定と提案文はこのPCの Claude Code（サブスク）を使う。新着10件まで／回
