# データ入力から始めるべきか（2026-09-06 調査の要約）

対象: YouTube 105本（ランキング系47 + データ入力系58）、募集中案件89件（ココナラ40 / ランサーズ29 / ママワークス20）、手元実データ256件。
生データ: 同ディレクトリの JSON。

## 結論
「データ入力*から*始める」は正しい。「データ入力*で*稼ぐ」は間違い。
- 人の労働としてのデータ入力: 1件3〜75円（中央値40円）、時給換算100〜500円。1件3円に929提案・採用1。→ やらない
- エンジンで受ける照合つきリスト作成: 1件200円以上 × 照合要件 × 法人公開情報 の3条件だけ受ける。月数千〜2万円が天井。→ 最初のレーン

## YouTube
- ランキング系47本: 推奨4 / 非推奨5 / 言及なし38。名指しは非推奨側（リベ大）。
- データ入力系58本: 稼げる派22 / 稼げない派18 / 条件付き18。検証系はほぼ全て稼げない（時給25・200・293円）。
  稼げる派は「AI活用」か「オンライン秘書等への乗り換え」が前提。64%がLINE/講座/スクール誘導。
- 最多再生140万回 = 「40時間で1,000円=時給25円」の検証動画。

## 実市場
- ココナラ募集中40件: 応募中央値4.5。純データ入力は少数。時給上限1,000円明記の案件あり。
- ランサーズ115件: 名目予算1〜2万円、詳細「実際の支払い300〜700円」。長期掲載案件は提案101〜929。
- ママワークス20件: 時給1,100〜1,800円（中央値1,250円）の継続稼働型。件単価は1〜10円も。
- 第三者記事: 初心者時給100〜500円、月3,000〜5,000円（3本一致）。
- 自動化適性: machine 48% / mixed 27% / human 25%。

## 進め方（3レーン）
1. 照合つきリスト作成 = 実績づくり
2. 出品4本（SDS・RA・手順書・ISO）= 待ちの収益
3. エンジンで受ける高単価定型（EC登録50〜300円/件、KDP登録1〜3万円、Word整形）= 本命
