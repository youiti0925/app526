## ジャンル定義と選定（genre-selection.html）
副業全体を「お金の入り方 × 成果物の担い手 × 何に払われるか」で10グループ（A転記 / B照合リスト / C仕様変換 / D専門判断 /
E制作受託 / F本人参加 / G継続契約 / H販売・広告 / I物販 / J自動化受託）に定義。
結論: 良いのは C（応募の主力）・D（出品の本命）・B（実績づくり）。A・G・H・I はやらない。E は条件付き。F は自動化の枠外だが最速の現金。
