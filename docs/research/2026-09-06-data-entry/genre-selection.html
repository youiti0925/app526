どのジャンルなら良いか

副業の全体を、市場のラベルではなく「お金の入り方 × 成果物の担い手 × 何に払われるか」で10グループに定義し直し、この案件で集めた証拠だけで選び直したものです。

結論

良いのは3つ。C 仕様変換（応募の主力）、D 専門判断（出品の本命）、B 照合リスト（実績づくり）。
データ入力は B の入口としてだけ正しい。

理由は単純で、この3つだけが「単価がある × 機械が主で人は承認だけ × 法・規約の壁がない」を同時に満たします。他は、単価が無い（A）、あなたの時間を売る（F・G）、客が来ない（H）、本人性か権利保証で詰む（E）のどれかです。

定義の軸

ジャンルを切る3つの軸

お金の入り方
応募型（締切と競争がある）/ 出品型（待ち。締切なし）/ 契約型（月額・時給、稼働時間の約束）/ 販売型（客を自分で集める）/ 参加型（本人がその場にいる）
成果物の担い手
機械のみ / 機械＋承認（あなたは要確認分だけ見る）/ 人の専門判断 / 本人性（顔・声・実績・体験）/ 現地・実物
何に払われるか
L0 転記 / L1 収集 / L2 照合 / L3 整形・変換 / L4 判断（前の報告書の定義）

この3軸で切ると、市場で「データ入力」「事務代行」「Webライター」「オンライン秘書」と呼ばれているものが、実は別グループに散らばっていることが分かります。

10グループ

定義・観測した証拠・判定

A　転記・入力型の事務（L0/L1）やらない
定義
渡された情報を決められた形に写す／探して写す。応募型。機械100%
市場の呼び名
データ入力、コピペ作業、名刺入力、レシート入力、商品リスト入力、OCR補正

1件3円の企業リスト作成に929提案・採用1名 / 件単価中央値40円 / 検証動画は時給25〜293円 / ママワークスのOCR補正1件1円

機械で100%できるのに受けない唯一の理由は、単価が無いこと。速さは誰にでもAIにもあるので価格競争が底まで落ちている。

B　照合・保証つきリスト作成（L2）実績づくりに使う
定義
集めた値を別ソースで裏取りし、正確さを保証して納める。応募型。機械＋承認
市場の呼び名
企業リスト作成、店舗情報収集、リストクレンジング、名寄せ、掲載確認

大阪ホテルリスト 1件200円×100件（34応募、発注者は前回の粗悪納品に懲りて品質を買いに来ていた）/ 国内企業リスト18応募・海外企業リスト23応募 / ランサーズ メーカーサイトリサーチ150件で5千〜1万円（44応募）

エンジン（抽出→照合→NG除外→検査）は完成済みで、あなたの作業は要確認行の目視だけ。単価はあるが天井が低い（月4〜6件出て取れて1〜2件、月2〜4万円）。ゼロから評価を作る場所として使う。壁: 個人情報（法人限定）、収集元の規約（Instagram等は手動・任意扱い）。

C　仕様変換・整形（L3）応募の主力にする
定義
決まった仕様の形に組み替える。応募型（一部出品可）。機械＋承認（仕様確認だけ人）
市場の呼び名
EC商品登録、モールCSV作成、KDP縦書き変換・登録、Word書式化、サイト移行、集計表作成、差し込み書類

募集中（9/6）: 楽天50商品登録（40応募）/ KDP縦書き変換+登録 1〜3万円（23応募）/ 準備済みHTMLのWix移行 1〜3万円（30応募）/ 論文の指定書式Word化（45応募）/ BUYMA出品作業 5千〜1万円（応募4〜6人）

データ入力の隣にあって単価が1桁上。仕様を一度コード化すれば毎回同じ処理で、機械の得意領域そのもの。正直に書くとこのグループの成果物はまだ試作していない（試作9件は記事・画像・動画・チラシ系だった）。応募前に1件、BUYMA/楽天のCSV作成かKDP変換を試作して納品水準を確認する。壁: 画像・説明文の転載可否、モール規約。

D　専門判断つき文書・技術サービス（L4）出品の本命
定義
専門知識で良し悪しを決め、責任ごと納める。出品型＋応募型。人の判断＋機械の下書き
市場の呼び名
SDS作成、化学物質リスクアセスメント、作業標準書・手順書、ISO文書整備、作業指示書テンプレ

出品4本（SDS 45,000円 / RA 90,000円 / 手順書 24,000円 / ISO 90,000円）承認済み・未出品 / 募集中: 自動車整備の作業指示書作成（76応募）、SDS 5物質（貼り付け起源）/ 2026-04 安衛法改正でSDS対象物質が拡大

あなたの製造業知識が売り物になる唯一のグループ。競争相手は「AIで量産する人」ではなく「資格や経験のある人」で、機械の下書き＋あなたの判断はここで一番効く。壁: 行政書士・税理士の業務に踏み込まない（既に台帳に線引き済み）、GHS区分はNITEの分類結果と決定的に照合。需要は未実証（出品して60日ルールで測る）。

E　制作受託（記事・画像・動画・デザイン）条件付き
定義
クリエイティブを作って納める。応募型／出品型。機械が作れるが、権利保証と本人性が壁
市場の呼び名
Webライター、記事作成、サムネ・チラシ、切り抜き動画、イラスト

試作9件: 発注者の目線で「払う」が5/9、返金が4/9（返金4件は全部、本人性か成果物違い）/ 本日の新着で「著作権譲渡」条件が2件（トレカ名刺・シンガー）→ 生成AIの規約上、独占性と非侵害の保証は約束できない / 切り抜き案件は3,000〜22,500円で契約0が続く

受けられるのは「AI利用可」と明記 × 独占的利用の保証なし × 本人の実績提示不要の3条件がそろう案件だけ。単価は下落中。主力にはしない。

F　本人参加型スポット（アンケート・インタビュー・モニター・体験談）自動化の枠外。ただし最速の現金
定義
本人がその場にいることに払われる。参加型。機械は関係ない
市場の呼び名
インタビュー協力、アプリモニター、体験談執筆、覆面調査

募集中（9/6）: 保護者インタビュー45分3,300円（応募1〜2人）/ アプリ動作確認1時間2,500円（30応募）/ 体験談2,000字1,000〜1,500円

正直に入れておきます。45分3,300円＝時給4,400円は、この報告書のどのグループより高い。自動化とは無関係で、あなたの時間を直接売る型。「少額でも今すぐ」が要るなら、条件に合うもの（本人属性が一致するもの）を月1〜2件は合理的。ただし伸びない。

G　継続契約型（準委任・時給・オンライン秘書・テレアポ）やらない
定義
稼働時間を約束して月額・時給で払われる。契約型。人の時間
市場の呼び名
フリーランス案件（週2〜5日）、在宅事務、オンライン秘書、テレアポ、カスタマーサポート

エージェント系16/17が月額準委任（40〜170万円/月、週3〜5日）/ ママワークス時給1,100〜1,800円 / YouTubeが「データ入力の代替」として推すオンライン秘書は月5〜7万円で週10〜20時間の稼働前提

単価は高いが「あなたの時間を10時間以上売る」型で、自動化・承認だけ、という前提と正面から衝突する。YouTubeがデータ入力からの乗り換え先に推すのはこれだが、それは時間の切り売りの単価が上がっただけ。

H　販売・広告収益型（ブログ・動画・デジタル素材・電子書籍・ツール販売）今はやらない
定義
作って置き、客が来て買う／広告が付く。販売型。機械が作れるが、客を集めるのは別の仕事

YouTube収益化: 登録者1,000人+4,000時間、量産型コンテンツは対象外（2025-07改定）/ PIXTAはAI素材から撤退（2026-05）/ KDPはAI申告義務 / メルカリはデジタル販売禁止 / 初収入まで中央値90〜240日（paths-data）

「自動販売機型」の理想形だが、客が来る部分が一番難しく、そこは自動化できない。Dが出品で売れ始めたら、その延長で「報告書自動作成ツール」に進む順番。先にここへ行くと数ヶ月無収入になる。

I　物販・無在庫やらない

メルカリは「手元にない商品」の出品を明文禁止 / 資金・在庫・実物の発送が要る / YouTubeランキングで上位に来るが、動画の発信者はスクール（30〜100万円）を売っている

J　自動化ツール・テンプレの受託（L3〜L4）試す価値あり（出品で）
定義
相手の業務を自動化する道具（スプレッドシート・スクリプト・テンプレ）を作って納める。応募型／出品型。機械が作り、人は要件確認

募集中: 広告出稿先企業リスト作成ツール開発（85応募）/ 業務自動化のアイデア壁打ち 月3,000円（13応募）/ 整備作業指示書のExcel化（76応募）/ 取引履歴の自動集計Excel（42応募、ただし税務計算は税理士法で不可）

うちの道具箱そのものが商品になる。ただし開発案件は応募が85と多く、納品後の保守を期待される。応募で取りに行くより、Dと同じく「製造業向けExcel自動化ツール作ります」の出品で需要を測るのが安全。

進め方

この順番で

  1. D を出す（今週）。承認済みの出品4本をココナラに置く。締切も競争もないので、置いた瞬間から60日の計測が始まる。
  2. C を1件試作する（今週）。BUYMA出品作業（応募4〜6人）か楽天CSV作成を、実際の募集文を使って納品水準まで作る。試作で通れば、以後この型はエンジンで即応する。通らなければ理由を台帳に書いて閉じる。
  3. B は自動で拾い続ける。L2以上・単価200円以上・法人公開情報の案件だけ承認デスクに上がる。締切切れは自動で下がる。取れた1件が最初の評価になる。
  4. F は本人属性が合う募集だけ、月1〜2件。自動化とは別枠の現金。
  5. J は D の出品が動いてから「製造業向けExcel自動化ツール」を出品で追加する。

畳む基準はこれまで通り: 応募30件・4週で返信ゼロなら応募先を変える / 1件で実作業8時間超ならその型を畳む / 出品60日で問い合わせゼロなら文面か価格を変える。
